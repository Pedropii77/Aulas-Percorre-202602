## 📂 Estrutura do repositório
 
```
Aulas-Percorre-202602/
├── HTML/        # Aulas de HTML: estrutura e semântica
├── CSS/         # Aulas de CSS: estilização, box model, flexbox
├── Interacao/   # Interação humano-máquina e prática com interfaces
├── LOGICA/      # Lógica de programação: funções e JavaScript
└── index.html   # Página inicial com o índice das aulas
```
 
| Pasta | Conteúdo |
|-------|----------|
| **HTML** | Fundamentos da linguagem de marcação |
| **CSS** | Estilização, Box Model, Header, Flexbox |
| **Interacao** | Atividades de interface e interação |
| **LOGICA** | Introdução a funções e lógica com JavaScript |

## 🚀 Como usar
 
1. Clone o repositório:
```bash
   git clone https://github.com/Pedropii77/Aulas-Percorre-202602.git
```
2. Entre na pasta:
```bash
   cd Aulas-Percorre-202602
```
3. Abra o `index.html` no navegador (ou use a extensão **Live Server** do VS Code).
